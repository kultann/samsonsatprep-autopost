Privacy Policy

This policy covers the Samson SAT Prep publishing tool ("the app"), which publishes SAT study content to the @samsonsatprep Instagram, TikTok and YouTube accounts.

What the app accesses

The app connects only to accounts owned by Samson SAT Prep. With the account owner's permission it uses basic account information (account ID and username) and permission to publish posts to that account. On YouTube, it uploads the channel owner's own videos to the owner's own channel and reads the channel's name and ID to confirm which channel is connected.

YouTube API Services

The app uses YouTube API Services. YouTube data is handled under the Google Privacy Policy. The app does not access, store or share any YouTube data other than the token needed to upload to the connected channel.

What the app does not do

The app does not collect, store, sell or share personal information about other users. It does not read messages, followers' data or comments.

Storage

Access tokens are stored as encrypted secrets and used only to publish scheduled posts. They are never shared with third parties.

Data deletion

The only data the app stores is the access token for each connected account. If access is revoked, or if you email a deletion request to the address below, the stored token is deleted within 7 days. The app keeps no copies of YouTube, Instagram or TikTok data.

Removing access

Access can be revoked at any time from Instagram (Settings → Apps and websites) TikTok (Settings → Security → Manage app permissions) or Google (Google security settings).
